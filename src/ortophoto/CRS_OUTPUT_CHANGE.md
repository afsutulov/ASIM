# Изменение выдачи результатов по CRS исходных ортофото

В этой версии модуль `ortophoto` больше не дублирует общий результат одновременно
в МСК-59 и WGS84.

Логика:

- исходный GeoTIFF в МСК-59 -> его найденные полигоны попадают только в
  `<model>_MSK59-<zone>.geojson`;
- исходный GeoTIFF в geographic CRS (включая EPSG:4326) -> его найденные
  полигоны попадают только в `<model>_WGS84_EPSG4326.geojson`;
- projected CRS, не распознанная как МСК-59 (например UTM), относится к
  международной группе и нормализуется в EPSG:4326;
- если в задании присутствует только одна группа исходных CRS, в ZIP создаётся
  только один соответствующий GeoJSON;
- если присутствуют обе группы, создаются оба GeoJSON, но результат каждого
  исходного снимка записывается только в один из них.

Метрические фильтры `min_area_m2` и `simplify` остаются корректными для всех
исходных CRS: перед их применением геометрия временно переводится в выбранную
зону МСК-59. Для WGS84-группы после фильтрации геометрия переводится обратно в
EPSG:4326.

Также в версии сохранены предыдущие исправления CUDA memory arena/retry.
